# Fontes pendentes para recursos futuros

O comparativo de antes e depois permanece pendente porque o catálogo de mídia atual não contém pares equivalentes do mesmo veículo, enquadramento e serviço. Para publicar esse recurso sem sugerir um resultado inexistente, a Auto Truck precisa fornecer ao menos uma foto de antes e uma foto de depois do mesmo processo.

As publicações recentes do perfil `@autotruck.estetica_` não estão disponíveis em fonte pública no navegador: o Instagram direciona o acesso ao login. A tentativa de ativar uma sessão autenticada de navegador foi recusada. Para montar uma galeria automática, será necessária uma sessão do Instagram conectada ou credenciais aprovadas para a API oficial da Meta; como alternativa, a equipe pode enviar uma seleção de postagens reais para publicação manual.
